# 👑 버거대왕의 국장 레이더

코스피200과 코스닥 시가총액 상위 150, 모두 350종목의 **차트를 매일 레이팅**하는 도구예요.
시그널이 뜬 종목을 누르면 **1/2 재무 점수 → 2/2 악재 스크리닝** 순서로 볼 수 있고, **총점 검색** 페이지에서는 종목별 총점을 확인할 수 있어요.
평일 18:10(한국시간)에 GitHub가 자동으로 실행해서 웹페이지를 새로 만들고, 새로 시그널이 뜬 종목은 텔레그램으로 알려줘요.

> 공부용 자동 분석이에요. 투자 권유가 아닙니다. 배점과 기준은 교과서적인 추정치이고, 아직 과거 데이터로 검증(백테스트)하지 않았어요.

## 처음 한 번만 하는 설정 (GitHub 웹사이트에서, 코딩 필요 없음)

1. **새 저장소 만들기**: GitHub → New repository → 이름 예: `kr-radar`
   - 미장 버전과 **다른 저장소**로 만드세요. 공개 웹페이지(GitHub Pages)는 저장소 하나에 하나만 둘 수 있어요.
2. **파일 올리기**: 압축을 푼 폴더 안의 파일을 전부 끌어다 놓고 Commit
   - `.github` 폴더는 이름이 점(.)으로 시작해서 숨김 파일로 처리돼 빠지기 쉬워요. 꼭 같이 올라갔는지 확인하세요.
3. **웹페이지 켜기**: Settings → Pages → Source를 **GitHub Actions**로 선택
4. **비밀 값 넣기**: Settings → Secrets and variables → Actions → New repository secret
   | 이름 | 값 | 필수? |
   |---|---|---|
   | `DART_API_KEY` | DART 인증키 (아래 참고) | 선택. 없으면 '공시 리스크'가 "확인 불가"로 표시돼요 |
   | `TELEGRAM_BOT_TOKEN` | 미장 버전에서 쓰던 봇 토큰 | 선택 |
   | `TELEGRAM_CHAT_ID` | 미장 버전에서 쓰던 채팅 ID | 선택 |
5. **첫 점검 실행**: Actions 탭 → kr-radar → Run workflow → **"데이터 출처 점검만 하기"에 체크** → Run
   - 실행이 끝나면 '데이터 출처 점검' 단계의 기록을 복사해서 Claude에게 보여주세요.
   - ⚠️ 네이버 페이지를 읽는 코드는 네이버 접속이 막힌 환경에서 만들었어요. 그래서 **실제 페이지로는 아직 한 번도 시험해 보지 않았어요.** 이 점검 결과를 보고 필요하면 고칩니다.
6. 점검에서 문제가 없으면 체크 없이 **Run workflow** → 몇 분 뒤 `https://내아이디.github.io/kr-radar/` 에서 페이지를 볼 수 있어요.

### DART 인증키 받는 법
opendart.fss.or.kr → 회원가입 → 인증키 신청/관리 → 발급받은 40자리 키를 `DART_API_KEY`에 넣으면 돼요. 무료이고, 하루 2만 번까지 조회할 수 있어요 (이 도구는 하루 약 350번 사용).

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `config.py` | **모든 숫자(배점·기준·비중)는 여기서만 바꿔요** |
| `sources.py` | 네이버 금융(시세·재무·수급)과 DART(공시)에서 데이터 받기. 실패하면 '실패'로 표시 |
| `universe.py` | 350종목 명단 (코스피200 + 코스닥 시총 상위 150, 우선주·스팩·ETF 제외, 바이오 포함) |
| `indicators.py` | 지표 계산 (이평선, MACD, RSI, 스토캐스틱, 일목균형표, 피보나치) |
| `signals.py` | 차트 시그널 판정, 국면(차트 모양) 판정, 차트 점수 100점 |
| `fundamental.py` | 재무 점수 100점, 악재 스크리닝, 총점 |
| `report.py` | 웹페이지 만들기 (`site/` 폴더) |
| `web/index.html` | 웹페이지 화면 (버거대왕 테마) |
| `web/burger-king.png` | 버거대왕 모델 시트 원본 (자르지 않음) |
| `notify.py` | 텔레그램 알림 (새로 뜬 시그널 / 사라진 시그널만) |
| `demo.py` | 가상 종목 350개로 화면을 시험하는 샘플 데이터 |
| `run.py` | 실행 입구 |
| `tests/` | 검증 테스트 33개 (자동 실행 때마다 먼저 돌아가요) |
| `.github/workflows/kr-radar.yml` | 평일 자동 실행 설정 |

## 직접 돌려볼 때 (선택)
```
pip install -r requirements.txt
python run.py --demo        # 가상 종목으로 화면만 확인
python run.py --diagnose    # 데이터 출처 점검
python run.py --limit 20    # 실제 데이터, 앞 20종목만
python run.py               # 실제 데이터, 350종목 전체
python -m pytest -q tests   # 검증 테스트
```
실행하면 `site/index.html`이 만들어지고, 브라우저로 열면 돼요.

## 알고 있는 한계
- **코스닥150 공식 명단**은 거래소 로그인이 필요해서 '코스닥 시총 상위 150'으로 대신해요. (pykrx도 최근부터 거래소 회원 로그인을 요구해요.)
- **EPS 추정치 변화, 애널리스트 상향·하향**은 무료로 안정적으로 받을 곳이 없어서 뺐어요. 대신 '올해 추정 영업이익 vs 작년 실적'으로 감익 예상 여부를 봐요.
- **실적 발표일 회피(블랙아웃)**는 국장에 미리 정해진 발표 일정표가 없어서 아직 빠져 있어요.
- 네이버 금융 페이지 구조가 바뀌면 일부 항목이 '확인 불가'로 바뀌어요. 페이지 아래 **왕의 규칙 → 데이터 상태** 표에서 실패한 건수를 확인할 수 있어요.
- 시세가 절반 이상 실패하면 페이지를 갱신하지 않고 어제 페이지를 그대로 둬요.
