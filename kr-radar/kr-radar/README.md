# 버거대왕의 국장 레이더

코스피 전 종목과 코스닥 시가총액 상위 150종목(약 900개)을 대상으로, 지금 과하게 빠진 종목을 찾고 과거에 같은 상태였던 날들이 어땠는지(횟수·승률·평균 수익)를 보여주는 도구.
공부용 자동 분석이며 투자 권유가 아니다.

## 대상과 그룹

코스피는 우선주·스팩·ETN·리츠·ETF를 뺀 보통주 전부, 코스닥은 시가총액 상위 150개.
신호가 없는 종목도 검색하면 차트·재무·기업 설명을 볼 수 있다.
등급은 종목이 속한 그룹의 과거 기록으로 따로 매긴다: 코스피 대형(시총 상위 200), 코스피 중소형, 코스닥 150.

## 규칙

과매도 조건이 두 개 이상 겹친 종목이 핵심 신호. 조건은 RSI 30 아래, 볼린저 하단 이탈, 20일선 대비 -10% 이격.
시장 폭(대상 종목 중 20일선 위인 비율)과 종목의 120일선 방향별로 과거 기록을 따로 센다.
등급은 5일 승률 기준(A 60 이상, B 55 이상, C 50 이상, 그 아래 D). 표본이 200회보다 적으면 더 넓은 조건으로 대신 센다.
52주 신고가 돌파, 거래량 실린 돌파는 따로 탭으로 본다.

효과가 없어서 뺀 것: MACD·RSI·스토캐스틱 골든크로스, 이평선 돌파, 20·60 골든크로스, 외국인·기관 순매수.

## 종목 화면 순서

차트 분석, 재무, 악재 스크리닝, 최종 판정.
최종 판정은 과거 5일 승률 50% 초과와 평균 수익 플러스이면 추천. 악재 점수가 60 미만이거나 재무 점수가 전 종목 하위 20%이면 비추.
재무 점수는 기준값이 아니라 전 종목 중 몇 퍼센트를 이겼는지로 매긴다. PER·PBR은 같은 업종끼리 비교한다.
순위는 전 종목, 같은 시장, 같은 업종 기준으로 보여준다.

## 실행

평일 09:05 ~ 15:35 30분마다 시세만 새로 받아 갱신 (장중 잠정).
평일 15:45, 18:10 전부 새로 받고 과거 성과표를 다시 계산, 텔레그램 알림.
급할 때는 GitHub Actions 화면에서 Run workflow (Re-run 아님). 코드 버전이 바뀐 첫 실행은 전부 새로 계산해서 오래 걸린다.

## 파일 (전부 run.py 와 같은 폴더)

- config.py — 모든 기준 숫자
- sources.py — 네이버 금융·와이즈리포트·DART에서 데이터 받기
- universe.py — 대상 종목 명단과 그룹 나누기
- indicators.py — 지표 계산과 신호 표시
- history.py — 그룹별 과거 성과표 만들기
- signals.py — 종목의 지금 상태 읽기 + 성과표에서 같은 상태 찾기
- fundamental.py — 재무 점수(상대 순위), 악재 스크리닝, 최종 판정
- run.py — 실행 입구
- report.py — 웹페이지와 폰 홈 화면용 설정 만들기
- notify.py — 텔레그램 알림
- index.html, burger-king.png — 화면과 그림
- icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png — 폰 홈 화면 아이콘
- checks.py — 검증 (자동 실행 때마다 먼저 돈다)
- demo.py — 가상 데이터로 화면 확인용
- measure.py — 조건별 과거 성과 측정 (Actions의 measure 에서 실행)

## 직접 돌려볼 때

    pip install -r requirements.txt
    python run.py --demo
    python -m pytest -q checks.py
