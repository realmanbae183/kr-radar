# 버거대왕의 국장 레이더

코스피·코스닥 350종목 중 지금 과하게 빠진 종목을 찾고, 과거에 같은 상태였던 날들이 어땠는지(횟수·승률·평균 수익)를 보여주는 도구.
공부용 자동 분석이며 투자 권유가 아니다.

## 규칙 (2026-10-05 측정으로 정함)

과매도 조건이 두 개 이상 겹친 종목만 후보로 본다. 조건은 RSI 30 아래, 볼린저 하단 이탈, 20일선 대비 -10% 이격.
시장 폭(350종목 중 20일선 위인 종목 비율)이 30% 미만인 날을 기회로 본다.
종목의 120일선이 오르는 중이면 더 믿는다.
5일에서 20일 들고 간다.
돌파는 시장도 종목도 상승 추세이고 거래량이 실렸을 때만 따로 본다.

효과가 없어서 뺀 것: MACD·RSI·스토캐스틱 골든크로스, 이평선 돌파, 20·60 골든크로스, 외국인·기관 순매수.

## 실행

평일 09:05 ~ 15:35 30분마다 시세만 새로 받아 갱신 (장중 잠정).
평일 15:45, 18:10 전부 새로 받고 과거 성과표를 다시 계산, 텔레그램 알림.
급할 때는 웹페이지의 '지금 갱신'을 눌러 GitHub 실행 화면에서 Run workflow.

## 파일 (전부 run.py 와 같은 폴더)

- config.py — 모든 기준 숫자
- sources.py — 네이버 금융·와이즈리포트·DART에서 데이터 받기
- universe.py — 350종목 명단
- indicators.py — 지표 계산과 신호 표시
- history.py — 과거 성과표 만들기
- signals.py — 종목의 지금 상태 읽기 + 성과표에서 같은 상태 찾기
- fundamental.py — 재무 점수, 악재 스크리닝
- run.py — 실행 입구
- report.py — 웹페이지 만들기
- notify.py — 텔레그램 알림
- index.html, burger-king.png — 화면
- checks.py — 검증 (자동 실행 때마다 먼저 돈다)
- demo.py — 가상 데이터로 화면 확인용

## 직접 돌려볼 때

    pip install -r requirements.txt
    python run.py --demo
    python -m pytest -q checks.py
